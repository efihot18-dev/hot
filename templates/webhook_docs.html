Webhook — Integracao com Discord
Endpoint de Compra Automatica

Configure seu bot do Discord para chamar este endpoint sempre que uma venda for confirmada. O sistema gera automaticamente o link de acesso e retorna no JSON.

POST
{{ base_url }}/api/purchase
Header obrigatorio:
Authorization: Bearer <sua_api_key>
Payload (JSON)
{
  "product_id": 1,
  "discord_user": "NomeDoComprador#0001",
  "quantity": 1
}
CampoTipoDescricao
product_idintID do produto cadastrado
discord_userstringNome do comprador (para log)
quantityintQuantidade de links (padrao 1)
Resposta (201 Created)
{
  "ok": true,
  "product": "VIP Mensal",
  "days": 30,
  "quantity": 1,
  "links": [
    "http://seu-host/acesso/AbCdEfGhIjKl..."
  ]
}
Envie os links ao comprador imediatamente — eles sao de uso unico e nao exibidos novamente no painel.
Exemplos de Integracao
import requests

API_URL = "{{ base_url }}/api/purchase"
API_KEY = "sk_..."   # coloque sua API key aqui

def gerar_acesso(product_id, discord_user, quantity=1):
    resp = requests.post(
        API_URL,
        headers={"Authorization": f"Bearer {API_KEY}"},
        json={
            "product_id": product_id,
            "discord_user": discord_user,
            "quantity": quantity,
        },
        timeout=15,
    )
    resp.raise_for_status()
    data = resp.json()
    return data["links"]   # lista de links de acesso

# Exemplo de uso
links = gerar_acesso(product_id=1, discord_user="User#1234")
print(links[0])  # envie este link para o comprador via DM

// discord.js v14 — exemplo em comando slash / evento de compra
const API_URL = "{{ base_url }}/api/purchase";
const API_KEY = "sk_...";  // coloque sua API key aqui

async function gerarAcesso(productId, discordUser, quantity = 1) {
  const res = await fetch(API_URL, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "Authorization": `Bearer ${API_KEY}`,
    },
    body: JSON.stringify({
      product_id: productId,
      discord_user: discordUser,
      quantity,
    }),
  });
  if (!res.ok) throw new Error(`Erro HTTP ${res.status}`);
  const data = await res.json();
  return data.links; // array de links
}

// No handler de compra / slash command:
const links = await gerarAcesso(1, interaction.user.tag);
await interaction.user.send(`Seu acesso: ${links[0]}`);
